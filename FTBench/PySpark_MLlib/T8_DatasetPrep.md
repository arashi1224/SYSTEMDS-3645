## Dataset Preparation Before Executing the T8 Benchmark File
1. Download application_train.csv from the following link (Ensure you have a Kaggle account first):

```
https://www.kaggle.com/competitions/home-credit-default-risk/data?select=application_train.csv
```

2. Place the file in the same folder as T8_PySpark.py

3. Rename the file to T8_Dataset.csv
