## Dataset Preparation Before Executing the T5 Benchmark File
1. Download train.csv from the following link (Ensure you have a Kaggle account first):

```
https://www.kaggle.com/competitions/santander-customer-transaction-prediction/data?select=train.csv
```

2. Place the file in the same folder as T5_panda.py

3. Rename the file to T5_Dataset.csv
